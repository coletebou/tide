# Welcome to Tide 🌊

Tide is a native code editor for iPad and iPhone in the spirit of VS Code.
This sample workspace lives in **On My iPad › Tide**, so you can also reach it from the Files app.

## Try these

| Action | Shortcut |
|---|---|
| Go to File | `⌘P` |
| Command Palette | `⇧⌘P` |
| Go to Symbol | `⇧⌘O` or `⌘P` then `@` |
| Go to Line | `⌃G` |
| Toggle Side Bar | `⌘B` |
| Toggle Terminal | ``⌃` `` |
| Find / Replace | `⌘F` / `⌥⌘F` |
| Toggle Comment | `⌘/` |
| Move Line Up/Down | `⌥↑` / `⌥↓` |

- Open `Sources/App.swift` and look at the minimap, sticky scroll and bracket colors.
- Open `data/broken.json` and check the **Problems** panel (`⇧⌘M`).
- Type `ls`, `tree` or `grep -rn TODO .` in the terminal.
